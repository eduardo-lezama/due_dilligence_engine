```python
def _render_citations_section(state: AnalysisState) -> list[str]:
    """
    Agrupa todas las citas de los agentes LLM por agente y las renderiza.
    Cada cita se muestra con claim, excerpt, confidence y URL clickable.
    Referencia ADR-014: auditoría del trail de claims cualitativos.
    """
    groups: list[tuple[str, list]] = []
    for field, label in [
        ("mgmt", "Management"),
        ("filings", "Filings (10-K)"),
        ("competitive", "Competitive & Moat"),
    ]:
        rep = state.get(field)  # type: ignore[literal-required]
        if rep is not None and not rep.stub and getattr(rep, "citations", None):
            groups.append((label, rep.citations))
    if not groups:
        return []
    lines = ["## Sources & Citations", ""]
    for label, cits in groups:
        lines.append(f"### {label}")
        lines.append("")
        for c in cits:
            conf = f"{c.confidence:.0%}"
            lines.append(f"- **{c.claim}** (confidence: {conf})")
            lines.append(f"  > {c.excerpt}")
            lines.append(f"  Source: [{c.source_url}]({c.source_url})")
            lines.append("")
    return lines
```

## ~~Task 2 (original: SqliteSaver)~~ — DEFERRED TO PHASE 5

**Status: deferred per [ADR-020](../../adr/ADR-020-checkpointer-deferred-to-phase-5.md).**

The original Task 2 proposed swapping `MemorySaver` → `SqliteSaver` in the CLI. This has been **removed from Phase 2 scope** after review.

**Why it was cut from Phase 2:**
1. **Known bug**: LangGraph's SqliteSaver serializes state via msgpack. `AnalysisState` contains Pydantic v2 sub-models (`FilingsReport`, `CompetitiveReport`, `ValueExpertReport`, `FinancialsReport`, …) which msgpack cannot encode without a custom `default=` hook. This is the exact failure observed in a previous session and why `cli.py:386-389` chose `MemorySaver` explicitly.
2. **No real use case in CLI single-user**: runs last < 3 minutes. `Ctrl+C → resume` is not an active workflow. The `archiver_node` already persists markdown + SQLite metadata.
3. **Value materializes in Phase 5 (webapp, NAS QNAP)**, where resume between browser sessions, multi-user, and durable threads matter. The serde decision (JsonPlusSerializer vs custom vs dict-state) is better made against the final state shape, not today's evolving one.

**Dependency is kept** (`langgraph-checkpoint-sqlite>=2.0.0` in `pyproject.toml`) — no uninstall in Phase 2 to avoid lockfile churn.

After Task 1 lands, **skip directly to the next task below**. The remaining Tasks (Peer ROIC, Transcripts, 8-K events, Expert prompt v2, Socratic checkpoints) keep their original numbering (Tasks 3 → 7) so cross-references stay stable.

```python
"""
Peers Node — fetches FinancialsReport for each user-supplied peer ticker.

Qué hace este módulo:
    Implementa peers_node, que recibe state["peers"] (lista de tickers aportada
    por el usuario en checkpoint1) y devuelve peer_financials: list[FinancialsReport].
    El competitive_agent consume esta lista para poblar peer_roic_comparison.

Por qué es un nodo separado y no inline en competitive:
    Permite caché por peer en SqliteSaver (Task 2) y paralelización futura.
    Además mantiene competitive_agent como LLM-lane puro — no hace I/O EDGAR.

Degraded mode:
    Si un peer falla (ticker inválido, XBRL corrupto), se loguea y se omite.
    Nunca bloquea el pipeline completo — peers es contexto, no dato crítico.

Referencia ADR: ADR-015.
"""

from __future__ import annotations

import structlog

from due_diligence.graph.state import AnalysisState
from due_diligence.schemas.base import FinancialsReport
from due_diligence.tools.edgar import DataUnavailableError, EdgarAdapter

log = structlog.get_logger()


def peers_node(state: AnalysisState) -> dict:
    """Itera sobre state["peers"] y fetcha FinancialsReport para cada uno."""
    peers: list[str] = state.get("peers", []) or []  # type: ignore[literal-required]
    if not peers:
        log.info("peers_node_skipped", reason="no peers provided")
        return {"peer_financials": []}

    reports: list[FinancialsReport] = []
    for peer_ticker in peers:
        try:
            raw = EdgarAdapter.fetch_raw(peer_ticker)
            rep = EdgarAdapter.parse_financials(raw)
            reports.append(rep)
            log.info("peers_node_fetched", peer=peer_ticker)
        except DataUnavailableError as e:
            log.warning("peers_node_peer_failed", peer=peer_ticker, error=str(e))
        except Exception as e:
            log.warning("peers_node_peer_unexpected", peer=peer_ticker, error=str(e))

    return {"peer_financials": reports}
```

```python
    @staticmethod
    def fetch_transcripts(ticker: str, quarters: int = 4) -> list[dict]:
        """
        Obtiene los últimos `quarters` transcripts de earnings calls (ADR-016).
        Each item: {id, year, quarter, date, prepared_remarks: str, qa: str}.
        Ordered most-recent first. Devuelve [] si FINNHUB_API_KEY no está set.
        """
        if not settings.finnhub_api_key:
            log.warning("finnhub_transcripts_skipped", reason="no api key")
            return []
        import finnhub  # type: ignore[import]
        client = finnhub.Client(api_key=settings.finnhub_api_key)
        try:
            listing = client.transcripts_list(ticker) or {}
        except Exception as e:
            log.warning("finnhub_transcripts_list_failed", ticker=ticker, error=str(e))
            return []

        items = sorted(
            listing.get("transcripts", []),
            key=lambda x: (x.get("year", 0), x.get("quarter", 0)),
            reverse=True,
        )[:quarters]

        results: list[dict] = []
        for item in items:
            tid = item.get("id")
            if not tid:
                continue
            try:
                full = client.transcripts(tid) or {}
            except Exception as e:
                log.warning("finnhub_transcript_fetch_failed", id=tid, error=str(e))
                continue
            prepared, qa = [], []
            in_qa = False
            for turn in full.get("transcript", []):
                text = " ".join(turn.get("speech", []))
                if "Q&A" in text[:60] or "question-and-answer" in text.lower()[:80]:
                    in_qa = True
                (qa if in_qa else prepared).append(
                    f"{turn.get('speaker','?')}: {text}"
                )
            results.append({
                "id": tid,
                "year": item.get("year"),
                "quarter": item.get("quarter"),
                "date": item.get("time"),
                "prepared_remarks": "\n".join(prepared),
                "qa": "\n".join(qa),
            })
        log.info("finnhub_transcripts_fetched", ticker=ticker, count=len(results))
        return results
```

```python
class EdgarEventsAdapter:
    """
    Adapter para obtener eventos 8-K estructurados de los últimos N meses.

    Cubre ADR-017: eventos materiales entre 10-K filings sin news APIs.
    Items relevantes por defecto:
      - 2.02: Results of Operations
      - 4.02: Non-Reliance on Previously Issued Financial Statements (restatement)
      - 5.02: Departure/Appointment of Directors and Officers
    """

    @staticmethod
    def fetch_8k_events(
        ticker: str,
        items: list[str] | None = None,
        months: int = 12,
    ) -> list[dict]:
        """Each event: {filing_date, item_numbers, summary_text, filing_url}."""
        if items is None:
            items = ["2.02", "4.02", "5.02"]
        from datetime import date, timedelta
        from edgar import Company, set_identity  # type: ignore[import]

        set_identity(settings.sec_user_agent)
        company = Company(ticker)
        start_date = (date.today() - timedelta(days=months * 30)).isoformat()
        filings = company.get_filings(form="8-K", date=f"{start_date}:")
        events: list[dict] = []
        for f in list(filings):
            try:
                obj = f.obj()
                filed_items = list(getattr(obj, "items", []) or [])
                matching = [i for i in filed_items if i in items]
                if not matching:
                    continue
                summary = str(getattr(obj, "summary", "") or "")[:600]
                events.append({
                    "filing_date": str(f.filing_date),
                    "item_numbers": matching,
                    "summary_text": summary,
                    "filing_url": getattr(f, "filing_url", ""),
                })
            except Exception as e:
                log.debug("8k_parse_failed", ticker=ticker, accession=str(f.accession_no), error=str(e))
                continue
        log.info("8k_events_fetched", ticker=ticker, count=len(events))
        return events
```

```python
def _compute_revenue_cagr_5y(revenue_series: list) -> float | None:
    """
    5-year revenue CAGR from the XBRL series (index 0 = most recent).
    Returns None if fewer than 2 usable points or the oldest value ≤ 0.
    """
    if len(revenue_series) < 2:
        return None
    newest = revenue_series[0].value
    oldest_idx = min(len(revenue_series) - 1, 4)
    oldest = revenue_series[oldest_idx].value
    if oldest <= 0 or newest <= 0:
        return None
    n = oldest_idx
    return (newest / oldest) ** (1 / n) - 1
```

```python
def _build_socratic_questions(state: AnalysisState) -> list[str]:
    """
    Generates 1-3 grounded, data-aware Socratic questions for Checkpoint 1.
    Each question is triggered by a detected pattern in the specialist outputs.
    Reference ADR-018.
    """
    qs: list[str] = []
    competitive = state.get("competitive")   # type: ignore[typeddict-item]
    financials = state.get("financials")     # type: ignore[typeddict-item]
    mgmt = state.get("mgmt")                 # type: ignore[typeddict-item]

    # 1) Moat vs ROIC mismatch
    if competitive and competitive.moat_classification and financials and financials.roic_series:
        roic = financials.roic_series[0].value
        moat = competitive.moat_classification
        if moat == "narrow" and roic > 0.20:
            qs.append(
                f"Competitive labeled moat '{moat}' but ROIC is {roic:.0%}. "
                "What specific signal would reconcile this, or indicate moat erosion?"
            )
        if moat == "none" and roic > 0.15:
            qs.append(
                f"No moat identified yet ROIC is {roic:.0%}. Is this cyclical, "
                "or is there a structural advantage the qualitative review missed?"
            )

    # 2) Management ownership / tenure
    if mgmt and mgmt.insider_ownership_pct is not None and mgmt.insider_ownership_pct < 1.0:
        qs.append(
            f"Insider ownership is only {mgmt.insider_ownership_pct:.2f}%. "
            "Would you weigh this as misaligned incentives or normal for a mega-cap?"
        )
    if mgmt and mgmt.ceo_tenure_years is not None and mgmt.ceo_tenure_years > 12:
        qs.append(
            f"CEO has been in the role {mgmt.ceo_tenure_years:.0f} years. "
            "Do you consider this continuity an asset or a succession risk?"
        )

    # 3) Peer prompt always present (ADR-015)
    qs.append("Which 3-5 peer tickers would you benchmark this company against?")
    return qs
```

```python
def _render_socratic_questions(state: dict) -> dict:
    from due_diligence.agents.checkpoint import _build_socratic_questions
    questions = _build_socratic_questions(state)
    answers: dict = {}
    if not questions:
        return answers
    console.print("\n[bold yellow]-- Socratic Questions (ADR-018) --[/bold yellow]\n")
    for i, q in enumerate(questions, 1):
        console.print(f"[bold]{i}.[/bold] {q}")
        ans = typer.prompt("   Your answer", default="")
        answers[f"q{i}"] = {"question": q, "answer": ans}
    return answers
```
